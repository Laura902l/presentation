Интерактивный урок: Воздух на джайляу чист (Жайлаудың ауасы таза)

Как открыть:
1. Распакуйте архив.
2. Дважды щёлкните по index.html — откроется в браузере (Chrome, Edge, Safari).
3. Нажмите ⛶ для полного экрана. Управление: стрелки клавиатуры, кнопки ‹ › или свайп.

Все картинки и код находятся внутри index.html (один файл, без папок).
Интернет нужен только для красивого шрифта Nunito; без интернета урок работает,
шрифт будет обычным. Звуки создаются самим браузером.
